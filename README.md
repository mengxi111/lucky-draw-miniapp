# 好运抽奖小程序

一个不依赖第三方框架的原生微信小程序演示，包含活动发现、活动详情、免费参与、创建活动、开奖记录、中奖领奖与本地数据持久化。

当前界面按参考产品改造成运营首页与可配置发布器：首页提供官方大奖、口令入口、活动预告、状态筛选和今日奖品；底栏为“首页 / 发起抽奖 / 我的”，开奖记录位于“我的”页面。创建页支持活动场景预设、完成度提示、配置预览、截止时间、每日次数、联系方式和补充说明；补充说明会同步显示在活动详情页。

创建页会自动保存未完成草稿，再次进入时可恢复；“我的”页面支持暂停或恢复自己发起的活动。暂停只影响后续参与，不会清除已有抽奖记录和领奖信息；活动跨过截止时间后仍会自动显示为已结束。

首页演示口令：`666`、`summer`、`coffee`、`camping`。

## 运行

1. 在微信开发者工具中导入本目录。
2. 体验模式可直接使用 `touristappid`；正式开发请在 `project.config.json` 中替换为自己的 AppID。
3. 编译后从首页选择活动，或进入“发起”创建一场本地活动。

本地版可完整体验实体奖品、优惠券和“即抽即中”。按时间/按人数开奖、红包、兑换码、商城履约和二维码上传统一列在“云端版扩展能力”中，不会伪装成可操作入口；它们需要服务端或云存储后才能正式启用。奖期“本机标记”只保存在当前设备，不会发送系统通知。

如果命令行提示“服务端口已关闭”，请直接在开发者工具选择“导入项目”；只有需要使用 CLI 时，才在“设置 → 安全设置”中开启服务端口。

也可以通过命令打开：


## 上线前必须替换的部分

当前抽奖、活动与领奖数据保存在当前设备的微信本地存储中，仅适合产品演示。真实活动必须把用户身份、参与资格、随机结果、奖品库存和领奖数据放到云开发或自有服务端，并通过一次服务端事务完成资格校验、扣次数、占库存和结果落库。

不要把付费、分享、关注、好友助力设为获得抽奖机会的条件。上线规则需明确主办方、活动时间、奖品数量、抽取方式、领奖期限、隐私用途与投诉方式。
